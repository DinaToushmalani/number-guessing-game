# 🎮 Number Guessing Game in Python

A fun, interactive little terminal game I built while learning Python! It’s a classic number guessing game, but I added a few extra features to make it cleaner and more engaging.

## 🌟 What's inside?
* **Difficulty Modes:** Pick your challenge! Choose from *Easy* (10 tries), *Medium* (7 tries), or *Hard* (5 tries).
* **Smart Input Handling:** It won't crash if you type weird characters, leave spaces, or put numbers outside the 1–100 range. (Special thanks to `.strip()` and `try-except` blocks!)
* **Smooth Flow:** You can easily quit anytime by typing `q`, or restart and play another round whenever you win or lose.

## ⚙️ How to run it locally
Make sure you have Python installed, open up your terminal, and run:

```bash
python game.py
## 🛠️ Built With

* Key concepts used: Loops, Functions, Exception Handling (`try-except`), and Input Validation.
